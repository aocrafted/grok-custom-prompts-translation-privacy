Grok Custom Prompts & Translation Switcher Privacy Policy

Last updated: November 2, 2026 · Developer: aocrafted

This independent browser extension helps you read and ask questions about individual X posts. It adds translation controls and lets you write a question in X’s native Grok panel. It is not affiliated with or endorsed by X or xAI.

Information the extension handles

  • Website content and post identifiers: The extension reads post text and relevant page structure on x.com and twitter.com to attach its controls. When you choose a post for a question, it reads that post’s author display name, handle, text, and URL to show the target card.
  • Authentication information: When you request a translation, it temporarily reads X’s existing ct0 anti-CSRF cookie and uses it, together with the browser’s existing X session, to authenticate a request to X. It does not ask for your password or API key and does not save authentication cookies in extension storage or send them to the developer. An in-memory SHA-256 digest of the anti-CSRF value separates translation caches between sessions/accounts.
  • Questions and chat content: When you submit your own question, the extension reads the current Grok input and adds the selected post’s URL to the first message. The question is then submitted through X’s native Grok interface. It does not read X direct messages or independently upload attachments.
  • Preferences: The extension stores its enabled state, language order, control size, and translation display preference in your browser.

Where information goes

  • A translation request sends the selected post ID, destination language, interface language, and necessary authentication headers/cookies over HTTPS to https://api.x.com/2/grok/translation.json. X returns the translated text.
  • Questions and the selected post URL go to X through its native Grok panel only when you submit them. Opening the panel does not submit a question or start an automatic summary.
  • The extension has no developer-operated backend, analytics, advertising, telemetry, or tracking scripts. It sends no post content, questions, account identifiers, or authentication information to the developer.
  • Data is not sold, used for advertising, or transferred for purposes unrelated to the extension’s core functionality. Its use of information complies with the Chrome Web Store User Data Policy, including the Limited Use requirements.

Storage and retention

  • Preferences and a cache-clear notification value are kept in chrome.storage.local until you change them or uninstall the extension. A rate-limit deadline is kept in chrome.storage.session for the browser session.
  • Up to 200 translations, keyed by session digest, post ID, and target language, are cached only in service-worker memory. Cached translations are eligible for reuse for 30 minutes; entries can remain in memory until eviction, cache clearing, or worker termination. Translations and session digests are not written to persistent extension storage.
  • The selected post and unfinished question are used in the current page/panel. The extension does not independently save chat history. X’s own chat history, retention, and privacy settings apply to information you submit to X.

Your control

  • Translations are requested only after you choose a translation language. “Original” restores the original post view; it does not undo information already sent to X.
  • Use “Clear cached translations” to clear the extension’s in-memory translations and cancel pending translation work. Turning the extension off also clears its translation cache. Neither action erases X’s own records or chat history.
  • Uninstalling removes the extension’s local preferences and session storage. Manage submitted questions and any retained X data through X/Grok settings.

External links

The optional “Buy me a coffee” link opens Buy Me a Coffee in a new tab without passing post text, questions, or authentication information. Payments are handled by that service; the extension does not receive payment details. This policy page is hosted on GitHub Pages. GitHub, X, and Buy Me a Coffee process visits and other information under their own privacy policies.

Contact and changes

For questions, open an issue in the privacy policy repository. Do not include credentials or private post/question content in a public issue. Material changes will be reflected here with an updated date.

Grok Custom Prompts & Translation Switcher プライバシーポリシー

最終更新日：2026年11月2日 · 開発者：aocrafted

このブラウザ拡張機能は、Xの投稿を読み、投稿について質問するためのツールです。言語切替を追加し、X標準のGrokパネルで自分の質問を入力できます。XまたはxAIの公式製品ではなく、承認や後援も受けていません。

扱う情報

  • ウェブサイトの内容と投稿の識別情報：x.comとtwitter.com上の投稿本文や必要な画面構造を読み、操作ボタンを配置します。質問対象を選ぶと、その投稿の表示名、ハンドル、本文、URLを読み、対象カードに表示します。
  • 認証情報：翻訳を要求したとき、Xの既存のct0（CSRF対策）Cookieを一時的に読み、ブラウザのXログイン状態とともにXへの認証に利用します。パスワードやAPIキーの入力は求めません。認証Cookieを拡張のストレージに保存したり、開発者に送信したりしません。セッション・アカウント別に翻訳キャッシュを分けるため、CSRF値のSHA-256ダイジェストをメモリ内で使用します。
  • 質問とチャットの内容：質問を送信するとき、Grokの入力内容を読み、最初のメッセージに対象投稿のURLを添えます。送信はX標準のGrok画面を通じて行います。Xのダイレクトメッセージは読まず、添付を拡張独自にアップロードすることもありません。
  • 設定：ON/OFF、言語の順序、ボタンの大きさ、翻訳結果の表示位置をブラウザ内に保存します。

情報の送信先と利用目的

  • 翻訳要求では、選んだ投稿のID、翻訳先言語、画面言語、認証に必要なヘッダー・Cookieを、HTTPSでhttps://api.x.com/2/grok/translation.jsonに送ります。Xから訳文を受け取ります。
  • 質問文と対象投稿URLは、利用者が送信したときにX標準のGrokパネルを通じてXへ渡します。パネルを開いただけでは質問を送信せず、自動要約も始めません。
  • 開発者独自のサーバー、アクセス解析、広告、テレメトリー、追跡スクリプトはありません。投稿内容、質問、アカウントの識別情報、認証情報を開発者へ送信しません。
  • データの販売、広告への利用、拡張の主な機能と関係のない目的での転送は行いません。情報の利用は、Limited Use要件を含むChromeウェブストアのユーザーデータポリシーに従います。

保存場所と保存期間

  • 設定とキャッシュ削除の通知値は、変更またはアンインストールまでchrome.storage.localに保存します。レート制限の終了時刻は、ブラウザのセッション中、chrome.storage.sessionに保存します。
  • 訳文は最大200件まで、セッションのダイジェスト・投稿ID・翻訳先言語をキーとして、サービスワーカーのメモリ内だけに保持します。再利用できるのは30分間です。項目自体は、件数上限による削除、キャッシュ削除、ワーカー終了までメモリに残る場合があります。訳文とセッションのダイジェストは、拡張の永続ストレージには書き込みません。
  • 対象投稿と未送信の質問は、現在のページ・パネルで使用します。拡張独自のチャット履歴は保存しません。Xへ送った内容には、X側の履歴、保存期間、プライバシー設定が適用されます。

利用者による管理

  • 翻訳は翻訳先の言語を選んだときだけ要求します。「原文」で投稿の表示を戻せますが、すでにXへ送った情報は取り消せません。
  • 「翻訳キャッシュを削除」で、拡張のメモリ内の訳文を削除し、処理中の翻訳を中止できます。拡張をOFFにしたときも翻訳キャッシュを削除します。これらの操作はX側の記録やチャット履歴を削除しません。
  • アンインストールすると拡張の設定とセッションストレージは削除されます。送信済みの質問やX側で保存されるデータは、X/Grok側の設定で管理してください。

外部リンク

任意の「Buy me a coffee」リンクは、投稿本文、質問、認証情報を渡さずに、Buy Me a Coffeeを新しいタブで開きます。支払いは同サービスが処理し、拡張は決済情報を受け取りません。このポリシーページはGitHub Pagesで公開しています。GitHub、X、Buy Me a Coffeeでのアクセスなどには、各サービスのプライバシーポリシーが適用されます。

お問い合わせと変更

プライバシーポリシー用リポジトリのIssuesからご連絡ください。公開Issueには認証情報や非公開の投稿・質問内容を書かないでください。内容を変更した場合は、このページと最終更新日を更新します。
